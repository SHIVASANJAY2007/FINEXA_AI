Typography
Source Serif 4 — Display/Editorial
Hero headline · Section headings · Pull quote · Pricing tier names · Footer CTA. Gives the cream palette its annual-report warmth. Letter-spacing: -0.02em. Replaces all-caps utility font-[1000] from TravelZyvox.
Inter — UI/Body
Navigation · Body copy · Badges · Chat bubbles · Form labels. Font-variant-numeric: tabular-nums for all ₹ figures. Weights 400/500/600/700/800. Replaces system default.

Key Design Principles (remapped)
1. Editorial-Finance Foundation
Soft borders, warm shadows, Source Serif 4 headlines. Replaces neo-brutalist hard black offsets with cream-glass editorial warmth.
2. Cinematic Scroll
Every section is a "scene." Unchanged from TravelZyvox — GSAP pin mechanics kept exactly, only colors and copy swap.
3. Gold Discipline — Max 3 Uses
Logo "AI" · "Recommended" badge · Stat numbers in WhyFINEXA. Never used a 4th time. Scarcity = premium signal.
4. Terracotta = Interaction Only
Nav hover underlines · Hero ping dot · Active states. Never in static layout. Hover states have their own identity — not just "burgundy but lighter."
5. Section Color Theming
Ivory → Burgundy → Teal → Cream → Ink. Each section has a distinct identity, not arbitrary. Teal = analytical trust. Burgundy = financial authority.
6. Privacy-First Messaging
"Financial advice shouldn't cost your privacy. FINEXA is your guard." — the brand promise that earns SDG 16. Replaces travel privacy messaging.
